# Self-Watering Plant System

## 📖 Project Description
A Soroban-based smart contract designed to automate plant watering by monitoring soil moisture levels and triggering irrigation when necessary.

## 🎯 Project Vision
To leverage smart contracts and decentralized technologies for smart agriculture and sustainable living. This contract ensures your plant never goes thirsty again!

## 🧩 Key Features
- **Moisture Monitoring**: Tracks real-time soil moisture levels.
- **Auto-Watering Toggle**: Users can enable or disable the auto-watering feature.
- **Intelligent Watering**: Automatically waters the plant when moisture falls below a critical level.
- **Ledger Timestamping**: Logs the last watered time using blockchain timestamps.

## 🔭 Future Scope
- Integrate with IoT devices and real sensors.
- Add support for multiple plants and owners.
- Implement thresholds that can be configured per plant type.
- Generate usage analytics and water conservation reports.
